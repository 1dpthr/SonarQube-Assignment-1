SONARQUBE ASSIGNMENT STARTER PACKAGE

Folders:
- before/: intentionally imperfect Java source for initial analysis
- after/: improved Java source for second analysis
- screenshots/: save your genuine SonarQube screenshots here

IMPORTANT:
1. Do not invent or copy metrics. Record the numbers shown by your own SonarQube instance.
2. Run each folder as a separate project key (e.g. student-management-before and student-management-after)
   or change sonar.projectKey before each scan.
3. Some intentional problems may not be reported by your SonarQube version/profile. Report actual findings only.
4. For the after scan, use a different project key or branch so you can compare the two analyses.
